Sauvegarde l\textquotesingle{}état d\textquotesingle{}une partie dans un fichier. 

Cette fonction enregistre les informations nécessaires à la reconstitution d\textquotesingle{}une partie, incluant la taille de la grille, le nombre de mines, la configuration des mines et de la grille utilisateur, le mode de jeu, le nombre de vies restantes, le nombre de tours de brouillage effectués, la couche d\textquotesingle{}objets et le temps écoulé. Elle utilise un format texte simple pour stocker ces données dans un fichier.
